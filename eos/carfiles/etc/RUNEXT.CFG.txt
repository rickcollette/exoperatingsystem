; RUNEXT.CFG - file associations for
; RUNEXT.SYS (DEVICE RUNEXT [file]).
;
; Format:
;  [!^]EXT[:EXT...],PROGRAM[,PARMS]
;  !  only with SHIFT held
;  ^  only with CTRL held
;  %  in PARMS: where the file name
;     goes; without it the name is
;     added at the end.
; Lines are tested in this order.
; A + before a command skips RUNEXT.
;
; ARC archives: list; CTRL: verbose
; list; SHIFT: extract here.
^arc,CAR:arc.com,V %
!arc,CAR:arc.com,X %
arc,CAR:arc.com,L %
;
; Text files: view with LESS.
txt:doc:man,CAR:less.com
