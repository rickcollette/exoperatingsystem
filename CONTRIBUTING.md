# Contributing

Do whatever you like with EOS. Use it, take it apart, fork it, port it, or
change it into something else.

If you have an idea or make a change that could help somebody else, it is
useful to send it back. Open an issue, make a pull request, or send a patch.
It does not have to be polished. Just say what you changed, why you changed
it, and what you tested.

Anything contributed to this repository is covered by the same MIT License
as the rest of EOS.
